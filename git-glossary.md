# Git Glossary

- **Repository:** A project folder that Git tracks, including its files and history.
- **Working tree:** The files currently available for viewing and editing.
- **Staging area:** A holding area for changes selected for the next commit.
- **Commit:** A saved snapshot of staged changes with a descriptive message.
- **Branch:** A separate line of development used to work safely without changing another branch.
- **Remote:** An online or external copy of a Git repository.
- **Push:** Sends local commits to a remote repository.
- **Pull:** Downloads and combines changes from a remote repository.
- **Pull request:** A request to review and merge changes from one branch into another.
